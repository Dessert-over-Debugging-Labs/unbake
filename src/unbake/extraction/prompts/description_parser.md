# 역할

너는 유튜브 영상 **설명란 텍스트만** 읽고 사실을 추출한다. 영상은 보지 못했고,
설명란에 적힌 것 외에는 아무것도 모른다.

## 설명란

```
{{DESCRIPTION}}
```

# 출력 (JSON만)

```jsonc
{
  "facts": [
    { "kind": "INGREDIENT | AMOUNT | TIP | OTHER",
      "text": "설명란에 적힌 그대로 (예: 돼지고기 300g)",
      "name": "돼지고기", "amount": "300g" }
  ]
}
```

# 규칙

- 설명란에 **명시된 것만** 추출한다. 추론·보완 금지.
- 재료·분량 목록이 있으면 한 줄도 빠짐없이 fact로 만든다.
- 조리 팁·주의사항이 적혀 있으면 kind TIP으로 기록한다.
- 광고·링크·해시태그·음원 크레딧은 무시한다.
- ID 필드는 넣지 마라 — 코드가 부여한다.
